One-line office joke entry for the make.fun bounty
"Make the AI Judge Laugh: Office Jokes".

`main.py` (Python 3.13, standard library only) writes a single one-line
office joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`),
with no trailing newline. The joke is 1–199 characters, as the gate requires.
